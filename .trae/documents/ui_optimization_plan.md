# UI 交互优化方案

## 需求分析

用户希望：
1. 将侧边栏中的组件配置（ComponentConfig）移到 Demo Tab 的 Config 中
2. 优化整体交互体验

## 当前问题

当前的组件配置功能分布在两个地方：
1. 侧边栏 ConfigPanel 中的 ComponentConfig - 用于启用/禁用组件和变体
2. Demo Tab 中的 ComponentConfigEditor - 用于配置具体的 token 值

这种分离导致用户需要在两个地方来回切换，体验不够流畅。

## 优化方案

### 方案三：模态框配置

点击组件时弹出模态框进行配置。

**界面布局**：

Demo Tab：
```
┌─────────────────────────────────────────────────────┐
│  [Button] [Input] [Textarea] [Select] [Config ▼]   │
├─────────────────────────────────────────────────────┤
│  组件预览区域...                                    │
└─────────────────────────────────────────────────────┘
```

点击 Config 按钮弹出模态框：
```
┌─────────────────────────────────────────────────────┐
│            Component Configuration                  │
├─────────────────────────────────────────────────────┤
│  Component: [Button ▼]                            │
│  Variant:   [Primary ▼]                           │
│  State:     [Default ▼]                           │
├─────────────────────────────────────────────────────┤
│  Property Configuration Table...                   │
├─────────────────────────────────────────────────────┤
│  [ Apply ] [ Cancel ] [ Reset ]                   │
└─────────────────────────────────────────────────────┘
```

**优点**：
- 界面简洁，配置不占主空间
- 适合配置操作不频繁的场景

## 建议的实现步骤

### 阶段一：移除侧边栏中的 ComponentConfig

**文件**：`src/components/config/ConfigPanel.tsx`
- 删除 Components 部分的代码

### 阶段二：增强 Demo Tab 的 Config

**文件**：`src/components/sandbox/ComponentConfigEditor.tsx`
- 添加组件启用/禁用功能
- 添加实时预览区域

### 阶段三：优化交互体验

**功能增强**：
1. 组件快速选择栏（点击切换启用/禁用）
2. 变体和状态的快捷切换
3. 属性搜索和过滤
4. 实时预览组件效果
5. 批量操作（全选/全不选组件）

## 预期效果

1. 用户可以在 Demo Tab 中完成所有组件配置操作
2. 实时预览配置效果
3. 交互流畅，操作直观

## 风险与注意事项

1. **界面复杂度**：过多的配置选项可能让用户困惑。解决方案：使用标签页或折叠面板分组功能。

2. **性能考虑**：实时预览可能影响性能。解决方案：使用防抖延迟更新预览。

3. **兼容性**：确保现有功能不受影响。解决方案：保持向后兼容。
